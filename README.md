# Polytech Robotique Lab

Laboratoire virtuel premium (Next.js + JavaScript) — **ERICC** & **NAO**.

## Lancer

```bash
cd polytech-robotique-lab
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## Parcours

1. Landing — entrée mondiale
2. `/lab/ericc` — 10 modules Partie 1 (dashboard, architecture, moteurs, capteurs, MGD/MGI, prise-dépose, 2 robots, apprentissage, validation, console)
3. `/lab/nao` — modules Partie 2 (DoF, postures, limites, capteurs, sonar, MGD, MGI/symétrie, Pepper, console)

## Stack

- Next.js 14 (App Router)
- React 18
- CSS custom (thème graphite / cyan signal)
